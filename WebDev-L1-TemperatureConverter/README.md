# Temperature Converter

## Oasis Infobyte Internship - Web Development & Designing

### Task
Level 1 - Task 3: Temperature Converter

## About

A simple temperature conversion tool that converts values between
Celsius, Fahrenheit and Kelvin.

## Features

- Numeric temperature input
- Celsius, Fahrenheit and Kelvin input selection
- Converts to all three units simultaneously
- Convert button
- Clear result display with unit labels
- Invalid input validation
- Absolute zero validation
- Responsive and centered UI

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
