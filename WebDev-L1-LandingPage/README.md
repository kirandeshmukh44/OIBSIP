# NEXORA - Landing Page

## Oasis Infobyte Internship - Web Development & Designing

### Task
Level 1 - Task 1: Landing Page

## About the Project

NEXORA is a modern and responsive landing page created for a fictional
digital solutions brand.

The project focuses on clean design, simple navigation and responsive
layout using only HTML5 and CSS3.

## Features

- Sticky navigation bar
- Four navigation links
- Hero section with headline and call-to-action button
- Features section with three service cards
- About section
- Testimonial section
- Contact call-to-action section
- Footer with social links
- Consistent colour palette
- Responsive design for mobile and desktop
- CSS Grid and Flexbox layout
- Clean and readable typography

## Tech Stack

- HTML5
- CSS3
