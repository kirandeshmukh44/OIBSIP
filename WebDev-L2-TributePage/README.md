# Tribute Page - Dr. A. P. J. Abdul Kalam

A responsive tribute page dedicated to Dr. A. P. J. Abdul Kalam, one of India's most respected scientists and the 11th President of India.

## Objective

The objective of this project is to create a visually engaging tribute page using HTML5 and CSS3.

## Technologies Used

- HTML5
- CSS3
- Google Fonts

## Features

- Subject name and tagline
- Prominent tribute image
- Biography section
- Key achievements timeline
- Notable quote section
- Multiple background colours
- Serif and sans-serif fonts
- Responsive design
- Mobile-friendly layout
- Styled achievement cards

## Sections

1. Hero Section
2. Image Section
3. Biography
4. Key Achievements
5. Quote
6. Footer
