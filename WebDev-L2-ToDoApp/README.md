# To-Do Web App

A simple and interactive To-Do List web application developed using HTML5, CSS3 and Vanilla JavaScript.

## Objective

The objective of this project is to create a web application that allows users to manage their daily tasks by adding, completing, editing and deleting tasks.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## Features

- Add new tasks
- Pending Tasks list
- Completed Tasks list
- Mark tasks as complete
- Edit tasks
- Delete tasks
- Pending task count
- Completed task count
- Empty state messages
- Task timestamps
- LocalStorage persistence
- Responsive design
- Enter key support for adding tasks

## Task Management

### Pending Tasks

New tasks are automatically added to the Pending Tasks list.

Users can:

- Mark the task as complete
- Edit the task
- Delete the task

### Completed Tasks

When a task is marked as complete, it moves from the Pending Tasks list to the Completed Tasks list.

Completed tasks show the completion timestamp.

## LocalStorage

Tasks are saved in the browser's LocalStorage.

This means the tasks remain available even after refreshing the page.
