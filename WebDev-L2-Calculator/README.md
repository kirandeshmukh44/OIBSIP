# Calculator

A simple browser-based calculator built using HTML5, CSS3 and Vanilla JavaScript.

## Features

- Addition, subtraction, multiplication and division
- Decimal number support
- Clear button
- Backspace button
- Division by zero error handling
- Operator chaining
- Responsive design
- CSS Grid layout
- JavaScript event listeners
- No inline onclick
- No eval()

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Open the project folder.
2. Open `index.html` in a web browser.
3. Use the calculator buttons.
